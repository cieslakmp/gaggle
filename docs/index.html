Gaggle

Push-to-talk voice chat for Condor Soaring Simulator

Hold a key or a joystick button, say your message, and Gaggle types it into Condor's in-game chat — so you can talk to the gaggle without taking a hand off the stick to type.

Speech recognition runs entirely on your own machine. No account, no API key, no cost, and no network round-trip in the middle of a race. Speak English, Polish, German or Spanish; anything that isn't English is translated to English on the way into chat.

Download for Windows

Latest release · Windows 10 or 11, 64-bit · free and open source

Windows will warn you the first time

This is expected, and it is not a virus warning. Gaggle isn't code-signed — a certificate is a recurring cost for a free tool — so the first launch shows "Windows protected your PC". That is SmartScreen reacting to an unknown publisher.

Click More info, then Run anyway. Windows also marks anything extracted from a downloaded zip as untrusted, and that mark follows the files out of the archive — clearing it on the zip before you extract saves the argument: 

Unblock-File .\Gaggle-win-x64.zip

Getting started

  1. Extract the zip somewhere permanent. Keep Gaggle.exe and the runtimes folder together — the executable on its own cannot load the speech model.
  2. Run it. Gaggle lives in the notification area; there is no main window.
  3. Right-click the tray icon → Speech model and pick one. It downloads once: 141 MB for English, or 465 MB if you want it to understand other languages.
  4. Right-click → Microphone for your headset, and Push-to-talk… to bind a key or a joystick button.
  5. Start Condor. The tray icon turns blue when everything is ready — then hold your button, speak, and release.

Good to know

  • You read every message before it sends. The transcript appears in a small overlay: Enter sends it, Escape discards it. Changed your mind mid-sentence? Keep holding the button past the recording limit and it is thrown away.
  • There's a hands-free mode for VR, where that overlay is a desktop window you cannot see. It sends without asking, so it warns you once before turning it on.
  • It updates itself. Gaggle checks for a new release once a day and offers it in the tray menu with the release notes. Nothing is touched until the download has been checked against its published checksum.
  • No installer, no admin rights, nothing in the registry. Settings and models live in %APPDATA%\Gaggle. Delete the folder and the executable and it is gone.
